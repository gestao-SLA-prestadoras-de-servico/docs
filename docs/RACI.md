# Planejamento Matriz RACI

| **R - Responsável** | Profissional designado para executar a tarefa devido o conhecimento necessário para tal |
| --- | --- |
| **A - Aprovador** | Profissional responsável por aprovar a demanda finalizada pelo Responsável |
| **C - Consultado** | Profissional capaz de dar ao Responsável o suporte necessário para que a tarefa seja melhor executada |
| **I - Informado** | Profissional que não participa diretamente do projeto, mas deve saber sua evolução |

> **Obs**.: O **Aprovador (A)** não deve ser o mesmo que o **Responsável (R)**, garantindo uma segunda perspectiva na validação da entrega e evitando que o próprio executor seja responsável pela aprovação de seu trabalho.
